# PURGATORY — UI Design Language

This document is the living source of truth for PURGATORY's visual UI language.

It records stable design decisions for colors, panels, typography, spacing, iconography, interaction states, and other presentation rules. It should evolve as the visual language is defined.

## Principles

- Prefer a cohesive, reusable visual language over one-off styling per screen.
- Record exact authored values when they are intentionally standardized.
- Distinguish established rules from experiments or temporary assets.
- Do not infer unspecified colors, dimensions, or behavior from nearby assets; document them explicitly once decided.
